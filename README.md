# iDataBase Client Avançado

Monorepo iDataBase Client Avançado. Baseline vigente: `IDB-FREEZE-AUTH-v5.6`, reconciliação documental derivada da v5.5 (não recuperação byte a byte da v5.4). A documentação normativa e o histórico estão no [repositório histórico](https://github.com/mackowen/idatabase-client-historico/tree/IDB-FREEZE-AUTH-v5.6/BASELINES/IDB-FREEZE-AUTH-v5.6).

Consulte o repositório histórico para campanhas, evidências, decisões e pendências. A Campanha 0004 adiciona persistência interna SQLite, isolada dos adapters de bancos externos; vault, histórico funcional, workers duráveis e interface de administração continuam em campanhas posteriores.
